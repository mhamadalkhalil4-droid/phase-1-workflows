Actor: Merchant · Screens: SCR-PP-002, SCR-PP-001 (edit mode), SCR-SCH
⚙️ Edit mode only: The Expected Increase % field is replaced by the Applied From date field (required). This date tells the system when to apply the changes to existing mandates.

Workflow 3 — Catch-up Collection Logic
Actor: System (fully automated) · Triggered after: Option A or Option B in Workflow 2 · Applies only to mandates flagged as replacing existing customers
⚙️ Key rule: New customer mandates do NOT receive catch-up add-ons. Only mandates flagged as replacing an existing customer go through this workflow. Frequency and max changes go to the plan and all mandates. Catch-up add-ons go to old-customer mandates only — never written into the plan.
flowchart TD A([START\nnew mandate approved by bank]) --> B[System calculates\nmissed payments:\nmissed days × collection amount\nOR payment difference × overlap periods] B --> C{Any missed\npayments\nto collect?} C -->|No| D([END\nNo catch-up needed ✓]) C -->|Yes| E{Main mandate\nfrequency?} E -->|Daily| F[Add missed payments\nas add-ons on next\nrecurring daily payments] F --> G{Max amount\nallows\nthe add-on?} G -->|Yes| H[Add-on collected\non next recurring\npayment day] G -->|No| I[System auto-increases\nmax on old-customer\nmandate to allow add-on.\nPlan max also updated.] I --> H E -->|Not Daily| J{Frequency allows\na nearby collection\nperiod?} J -->|Yes| K[System schedules\ncatch-up in next\nfrequency period] J -->|No — too infrequent| L[System permanently\nincreases mandate frequency\nto create a closer period.\nPlan frequency also updated.] L --> K K --> M[Catch-up added as\nadd-on in next period\non old-customer mandate] H --> N[Catch-up add-ons written\nto old-customer mandates only.\nNew customer mandates\nnot affected.] M --> N N --> O([END\nCatch-up Collected ✓]) classDef sys fill:#4E465E,color:#fff,stroke:#333,stroke-width:1.5px classDef dec fill:#F59E0B,color:#fff,stroke:#D97706,stroke-width:1.5px classDef ok fill:#22C55E,color:#fff,stroke:#16A34A,stroke-width:1.5px class A,D,O ok class B,F,H,I,K,L,M,N sys class C,E,G,J dec
